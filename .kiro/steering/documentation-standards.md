# VELTRIX Steering: Documentation Standards
**Category:** Documentation Quality & Developer Experience  
**Scope:** README, API Docs, Architecture Diagrams, Demo Scripts  

## 1. Documentation Requirements
- Every repository module must include clear `README.md` documentation explaining its purpose, dependencies, and testing commands.
- All REST API endpoints must document request bodies, query parameters, authorization headers, and sample response payloads.
- Cloud architecture diagrams must use Mermaid code blocks or high-resolution PNGs with accessible descriptions.

## 2. Competition & Evaluation Readiness
- Include a 5-minute competition demonstration walkthrough script (`docs/demo-script.md`).
- Document explicit steps to run the 6 pre-built attack simulations.
- Provide transparent AWS cost breakdowns matching AWS Pricing Calculator estimates.
